# Central de Inteligência JARVIS - Dossiês & Pesquisas

Este diretório armazena automaticamente todos os resumos, pesquisas e notas técnicas geradas pelo JARVIS.

- Cada pesquisa é salva com timestamp e título estruturado.
- Você pode ler, editar e compartilhar esses arquivos a qualquer momento.
- A interface do JARVIS permite visualização em tempo real e abertura direta no Windows.
